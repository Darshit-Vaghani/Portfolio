Project Overview

This project implements a sophisticated phase-angle control system for AC motors using TRIAC technology with zero-crossing detection. The design allows precise speed and voltage regulation while maintaining compatibility with various microcontrollers for automation applications.

Key Features

Precise Phase-Angle Control

Smooth motor operation with accurate voltage regulation

Zero-Crossing Detection

Reduced electrical noise and improved efficiency
