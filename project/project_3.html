Project Overview

An IoT-enabled LPG leakage detection system that monitors gas levels using MQ-6 sensor and automatically shuts off supply via servo-controlled valve to prevent accidents.

Key Features

Real-Time Gas Monitoring

Detects LPG concentration instantly.

Auto Valve Shut-Off

Servo closes gas line on detection.

Audio-Visual Alert

Buzzer + flashing LED warning.

Achievements

Prevented potential gas explosions in testing

Key Learnings

Gas Sensor Calibration

Learned MQ-6 sensitivity and threshold tuning.

Servo Control Logic

Implemented fail-safe valve closure.

Safety Protocols

Designed for zero false negatives.
